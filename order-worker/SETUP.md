# এক-পেজ অর্ডার সার্ভার (Cloudflare Worker) — সেটআপ

কার্ট পেজের ফর্মে কাস্টমার নাম, ফোন আর ঠিকানা দিয়ে "অর্ডার করুন" চাপলে কী হয়:

1. ফর্মের তথ্য এই Worker-এ যায়।
2. Worker Shopify থেকে দাম আর স্টক মিলিয়ে দেখে।
3. Worker Shopify-তে **Cash on Delivery অর্ডার** তৈরি করে, ডেলিভারি চার্জ ৳৮০ বা ৳১২০ সহ।
4. কাস্টমার একই পেজে "ধন্যবাদ, অর্ডার নম্বর #1001" দেখেন। Shopify-এর আলাদা চেকআউট পেজে যেতে হয় না।

> 🔒 সিক্রেট কী (Client secret) কখনো চ্যাটে পাঠাবেন না। শুধু নিচের টার্মিনাল কমান্ডে নিজে পেস্ট করবেন।

## ধাপ ১ — Shopify-তে একটা অ্যাপ বানানো (আপনি করবেন, ~১০ মিনিট)

Worker যেন আপনার স্টোরে অর্ডার তৈরি করতে পারে, তার অনুমতির জন্য এই অ্যাপ লাগবে।

1. **ghorerposhakbd@gmail.com** দিয়ে Shopify-তে লগইন থাকা অবস্থায় যান: **https://dev.shopify.com**
   - অথবা Shopify Admin → Settings → Apps → **Develop apps** → **Build apps in Dev Dashboard**
2. **Create app** → নাম দিন `Ghorer Poshak Order Form` → **Start from Dev Dashboard**।
3. **Versions** ট্যাবে:
   - **App URL:** `https://ghorerposhak.com`
   - **Scopes**-এ এই পাঁচটা দিন (কমা দিয়ে):
     ```
     write_orders,read_orders,read_products,write_customers,read_customers
     ```
   - **Release** চাপুন।
4. **Home** বা **Overview** পেজে **Install app** চাপুন → আপনার স্টোর **Ghorer Poshak** বেছে নিন → **Install**।
5. **Settings** ট্যাবে **Client ID** আর **Client secret** দেখতে পাবেন। এগুলো ধাপ ৩-এ লাগবে।
   - Client ID আমাকে বললেও সমস্যা নেই।
   - **Client secret কাউকে দেবেন না।**

## ধাপ ২ — Cloudflare-এ লগইন (আপনি করবেন, ১ মিনিট)

Ghorer Poshak ফোল্ডারে টার্মিনাল খুলে চালান:

```bash
cd "/home/rabiul/Desktop/Ghorer Poshak/order-worker" && source ~/.nvm/nvm.sh && nvm use 22 && npx wrangler login
```

ব্রাউজার খুলবে। যে Cloudflare অ্যাকাউন্টে ghorerposhak.com ডোমেইন আছে, সেটা দিয়ে **Allow** দিন।

এরপর আমি নিজেই এগুলো করতে পারব:
- অর্ডারের রেকর্ড রাখার জায়গা (KV) তৈরি করা
- Worker ডিপ্লয় করা
- থিমে সার্ভারের লিংক বসানো

## ধাপ ৩ — Shopify-এর চাবি দুটো Cloudflare-এ রাখা (আপনি করবেন, ১ মিনিট)

**আমি Worker একবার ডিপ্লয় করার পরে** একই টার্মিনালে চালান:

```bash
npx wrangler secret put SHOPIFY_CLIENT_ID
```
জিজ্ঞেস করলে Client ID পেস্ট করে Enter দিন।

```bash
npx wrangler secret put SHOPIFY_CLIENT_SECRET
```
জিজ্ঞেস করলে Client secret পেস্ট করে Enter দিন।

চাবিগুলো সরাসরি Cloudflare-এ এনক্রিপ্ট হয়ে জমা থাকে। কোনো ফাইলে বা চ্যাটে যায় না।

## ধাপ ৪ — টেস্ট (আমি করব)

1. একটা টেস্ট অর্ডার দিয়ে দেখব।
2. অর্ডারটা Shopify Admin → Orders-এ ঠিকমতো এসেছে কিনা মিলিয়ে নেব।
3. তারপর আপনার অনুমতি নিয়ে টেস্ট অর্ডারটা ক্যান্সেল করব।

## যা যা সুরক্ষা আছে

| ঝুঁকি | সুরক্ষা |
|---|---|
| ব্রাউজার থেকে কেউ দাম বদলে পাঠাল | দাম সবসময় Shopify থেকে নেওয়া হয়, ব্রাউজারের পাঠানো দাম কাজে লাগে না |
| স্টক শেষ এমন পণ্য বা সাইজ | অর্ডার নেওয়ার আগেই আটকে দেয় আর বাংলায় কারণ দেখায় |
| ডাবল ট্যাপ বা নেট সমস্যায় দুবার অর্ডার | একই চেষ্টা থেকে একটাই অর্ডার তৈরি হয় |
| স্প্যাম বা বট | লুকানো ফাঁদ-ঘর আছে; এক IP থেকে ঘণ্টায় ৬টা আর এক ফোন থেকে ঘণ্টায় ৪টার বেশি অর্ডার নেয় না |
| অন্য ওয়েবসাইট থেকে অর্ডার পাঠানো | শুধু ghorerposhak.com থেকে আসা অর্ডার গ্রহণ করে |

**ডেলিভারি চার্জ বদলাতে:** `wrangler.jsonc` ফাইলে `DELIVERY_INSIDE` / `DELIVERY_OUTSIDE` বদলাতে হবে। একই সাথে থিম সেটিংসেও বদলাতে হবে, যেন সাইটে দেখানো চার্জ আর অর্ডারের চার্জ এক থাকে। আমাকে বললে দুটোই করে দেব।

## খরচ

- **Cloudflare Workers:** ফ্রি প্ল্যানে দিনে ১ লাখ রিকোয়েস্ট পর্যন্ত বিনামূল্যে।
- **KV:** ফ্রি প্ল্যানে দিনে ১,০০০টা লেখা পর্যন্ত। প্রতিটা অর্ডারে ৩-৪টা লেখা হয়, তাই দিনে ~২৫০টা অর্ডার পর্যন্ত ফ্রি।
- এর বেশি অর্ডার হলে Workers Paid প্ল্যান লাগবে, মাসে $৫।
